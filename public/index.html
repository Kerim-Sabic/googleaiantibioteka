🏥 BAA-2025

Bosnia & Herzegovina Antibiotic Advisor

Hospital-Grade Clinical Decision Support System

⚕️ For Healthcare Professionals Only

This system recommends ONLY medications registered in the Registar lijekova Bosne i Hercegovine 2025

System Features

  • Zero Hallucinations: Only recommends drugs actually available in BiH
  • Brand-Specific: Provides exact trade names, manufacturers, and formulations
  • Regulatory Aware: Distinguishes between ZU (hospital-only) and Rp (prescription) drugs
  • Automatic Substitutions: Replaces unavailable international drugs (e.g., Nafcillin → Syntarpen)
  • Dose Calculations: Pediatric weight-based, renal adjustments, hepatic dosing
  • Safety Checks: Allergy verification, drug interactions, contraindications

Drug Registry Coverage

β-Lactams

Penicillins, Cephalosporins (1st-5th gen), Carbapenems

Fluoroquinolones

Ciprofloxacin, Levofloxacin, Moxifloxacin

Other Antibacterials

Macrolides, Aminoglycosides, Vancomycin, Linezolid

Antifungals & Antivirals

Azoles, Echinocandins, HIV/HCV agents

Supported Clinical Scenarios

  • Community-Acquired Pneumonia (CAP)
  • Hospital-Acquired Pneumonia (HAP) / Ventilator-Associated Pneumonia (VAP)
  • Urinary Tract Infections (Cystitis, Pyelonephritis)
  • Bacterial Meningitis
  • Skin & Soft Tissue Infections
  • Intra-Abdominal Infections
  • Sepsis & Septic Shock
  • Neutropenic Fever

API Documentation

The BAA-2025 system provides a RESTful API for integration with hospital information systems.

Endpoints:

  • POST /api/recommend - Generate antibiotic recommendation
  • GET /api/drugs/search?generic={name} - Search drugs by generic name
  • GET /api/drugs/antipseudomonal - List all antipseudomonal drugs
  • GET /api/drugs/anti-mrsa - List all anti-MRSA drugs
  • GET /api/health - Health check

Example Request:

POST /api/recommend
{
  "patient": {
    "demographics": {
      "age_years": 35,
      "gender": "male",
      "weight_kg": 75
    },
    "physiology": {
      "serum_creatinine_mg_dl": 1.2
    },
    "allergies": []
  },
  "infection": {
    "site": "community_acquired_pneumonia",
    "acquisition": "community_acquired",
    "severity": "moderate"
  }
}
